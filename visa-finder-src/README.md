# Japan Visa Finder

An interactive single-page quiz to help users discover their path to a Japan visa.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Flow

1. **Phase 1 – Demographics**: Gender, age, relationship status, partner details
2. **Phase 2 – Passport**: Non-Israeli passport check, Working Holiday Visa (31 countries)
3. **Phase 3 – Entrepreneur & Culture**: Business/startup investment, traditional arts
4. **Phase 4 – Employment**: Working status, income, remote work, degree, savings
5. **Phase 5 – Specialist**: Nursing/construction/farming + N4 Japanese
6. **Finale**: Spouse “Hail Mary” (if no other path matches)

## Tech

- Next.js 14 (App Router)
- React 18
- TypeScript
- Tailwind CSS
